# GitKeepr v0.1.0

GitKeepr v0.1.0 is the first operationally validated V1 release.

## Highlights

- GitHub-native Build ↔ Review loop driven by PR events, trusted comments, submitted reviews, and manual dispatch.
- Persistent per-repository self-hosted runners managed by `gitkeepr runner add/remove`.
- Ubuntu/Debian server bootstrap and diagnostics with `gitkeepr server init/doctor`.
- GitHub App authentication for repository mutations.
- Configurable Build/Review OpenCode models and variants.
- Multi-cycle Review `CONTINUE` → Build correction → Review `PASS`.
- No-progress blocking, success-only trigger idempotence, no-build suppression, and direct no-code replies.
- Public GitKeepr self-development protected by a GitHub-hosted same-repository gate; fork PRs never reach the persistent runner.
- Release-pinned distribution: installer, project template, and standard reusable workflow all stay on `v0.1.0` until explicitly upgraded.

## Validated environment

Live end-to-end validation was performed on Ubuntu 22.04 LTS on ARM64. The CLI also supports amd64/x64 by contract, but that architecture was not part of this live V1 smoke run.

## Install

```bash
curl -fsSL https://github.com/MatousekJakub/gitkeepr/releases/latest/download/install.sh | bash
```

Then follow `docs/setup.md`.

## Upgrade behavior

Installing a newer GitKeepr release updates the CLI only. Run `gitkeepr init` inside each managed private repository to review and explicitly update its release-pinned `.github/workflows/gitkeepr.yml`. Existing repository runners do not need to be re-registered merely because the CLI version changed.
